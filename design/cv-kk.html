Ақпараттық технологиялар, жүйелік интеграция, интернет: интернет-компания (іздеу жүйелері, төлем жүйелері, әлеуметтік желілер, ақпараттық-танымдық және ойын-сауық ресурстары, сайттарды жылжыту және т.б.); жүйелік интеграция, кәсіпорынның технологиялық және бизнес-процестерін автоматтандыру, IT-консалтинг.

Міндеттер

  • C# және .NET-те серверлік қосымшалар мен сервистерді әзірлеу және сүйемелдеу, техникалық талаптар бойынша бизнес-логиканы іске асыру
  • ASP.NET Core (Web API)-да Swagger құжаттамасы бар REST API
  • Entity Framework Core және LINQ арқылы деректермен жұмыс, өнімділік маңызды жерде тікелей SQL-сұраныстар
  • Дерекқор құрылымы мен SQL-сұраныстарды жобалау және оңтайландыру (PostgreSQL, MS SQL Server), Redis-те кэштеу
  • Сыртқы API және үшінші тарап жүйелерімен интеграция (SOAP, Apache Kafka), сервистерді Docker-ге орау, CI/CD арқылы құрастыру және жариялау
  • xUnit-тегі бизнес-логиканың unit-тесттері, асинхронды өңдеу (async/await)
  • Продакшендегі қателерді табу және түзету, жұмыс істеп тұрған сервистерді сүйемелдеу
  • Тапсырмаларды бағалау, Agile/Scrum бойынша жұмыс, талаптарды нақтылау және шешімдерді таныстыру үшін тапсырыс берушілермен тікелей байланыс
  • Тағылымдамашыларға жетекшілік ету, code review-ға қатысу

Осы жұмыстағы кейстер

01Есептер мен дерекқор сұраныстарын жылдамдату
Міндет

Жүйенің негізгі есептері мен экрандары тым ұзақ ашылатын, үлкен көлемді деректерде кейбір сұраныстар таймаутқа түсетін. Пайдаланушылар шағымданып, дерекқор серверіне жүктеме өсті.

НәтижеНегізгі есептерді қалыптастыру уақыты 15 секундтан 2 секундқа дейін қысқарды, таймауттар жойылды, дерекқор серверіне жүктеме 40%-ға төмендеді.
Шешім
  • Баяу сұраныстарды орындалу жоспарлары арқылы талдадым (PostgreSQL-де EXPLAIN ANALYZE)
  • Ауыр сұраныстарды қайта жаздым: артық JOIN-дар мен қажетсіз бағандарды алып тастадым, курсорлар мен циклдерді set-based операциялармен алмастырдым
  • Жетіспейтін және құрама индекстерді қостым, пайдаланылмайтындарын алып тастадым
  • Интерфейс бұғатталмауы үшін ұзақ операцияларды асинхронды өңдеуге (async/await) көшірдім
C#.NETPostgreSQL
02Сыртқы жүйелермен асинхронды интеграция
Міндет

Жүйеге бірнеше сыртқы сервистермен және іргелес жүйелермен деректер алмасу қажет болды. Синхронды шақырулар негізгі процесті баяулататын, ал сыртқы тарап қолжетімсіз болғанда деректер жоғалатын немесе оларды қолмен қайта жіберуге тура келетін.

Нәтиже10-нан астам сыртқы жүйе қосылды, тәулігіне мыңдаған хабарлама өңделеді, деректерді қолмен қайта жіберу енді қажет емес. Негізгі процесс сыртқы жүйелердің жауабын күтпейді және олардың қолжетімділігіне тәуелді емес.
Шешім
  • Интеграциялық қабатты жобалауға қатысып, оны әзірледім: сыртқы API үшін SOAP, сервистер арасындағы асинхронды алмасу үшін Apache Kafka
  • Бір тараптағы ақау деректердің жоғалуына әкелмеуі үшін қайта жіберуді, қателерді өңдеуді және журналдауды іске асырдым
  • SOAP-сервистердің WSDL келісімшарттарымен жұмыс істедім, сервистерді Docker-ге орадым, CI/CD арқылы құрастыру мен жариялауды баптауға қатыстым

03Бизнеске арналған есептілігі бар клиент-серверлік модуль
Міндет

Бизнеске деректермен жұмыс істеуге және баспа формалары мен есептерді шығаруға арналған жаңа модуль қажет болды. Бұрын есептер Excel-де қолмен жиналатын.

НәтижеМодуль бірнеше айда іске қосылды, есептер қолмен жиналудың орнына автоматты түрде қалыптасады, бұл аптасына ондаған сағат үнемдейді. Модульді мыңдаған қызметкер пайдаланады.
Шешім
  • Командамен бірге талаптарды тікелей тапсырыс берушіден жинадым, мерзімдер мен еңбек шығынын бағалап, шешімді таныстырдым
  • .NET-те серверлік бизнес-логиканы іске асырдым
  • Модульге арналған дерекқор құрылымын әзірледім
  • StimulSoft Reports-та есептер мен баспа формаларын жасадым
  • Негізгі логиканы unit-тесттермен қамтыдым, код code review-дан өтті. Әзірлеуге мен жетекшілік еткен тағылымдамашылар қатысты

Мен туралы

Мен C# және .NET платформасындағы коммерциялық backend әзірлеуде 5 жылдан бері жұмыс істеймін (2021 жылдан бері). PBSOFT компаниясында серверлік логиканы, клиент-серверлік модульдерді және сыртқы жүйелермен интеграцияларды әзірлеп, сүйемелдедім. Дерекқорлармен көп жұмыс істеймін: SQL сұраныстары мен дерекқор құрылымын оңтайландырамын (PostgreSQL, MS SQL Server), асинхронды өңдеуді қолданамын (async/await, Apache Kafka), SOLID және Clean Code қағидаттарын ұстанамын. 2026 жылдың сәуірінен бастап фрилансте жұмыс істеймін: жеке тапсырыстар орындаймын және жеке жобаларымды дамытамын.

Қандай пайда бере аламын

  • Серверлік әзірлеу және интеграциялар: .NET-те бизнес-логика мен API, SOAP және Apache Kafka арқылы сыртқы жүйелермен интеграция, продакшендегі қателерді табу және түзету.
  • Дерекқорлар: кесте құрылымы мен индекстер, орындалу жоспарлары бойынша баяу сұраныстарды табу және оңтайландыру.
  • Команда және тапсырыс беруші: code review-ға қатысамын, тағылымдамашылардың бейімделуіне көмектесемін, тапсырмалардың мерзімін бағалаймын, тапсырыс берушімен тікелей сөйлесемін.
  • Білім: бейінді жоғары білім (Қолданбалы информатика) + Cisco сертификаттары (Networking & Cybersecurity).
